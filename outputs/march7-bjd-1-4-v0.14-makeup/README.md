# 三月七 v14 妆面与眼睛预览

以已经确认的 v14 素头另存制作。主头壳与后盖的顶点、三角、形状和尺寸保持不变，旧版素头文件未改动。使用本地原三月七模型的脸部贴图、粉蓝虹膜、眉睫及口部视觉附件，提供多角度观感预览。

## 打开模型

用 Blender「文件 → 打开」打开 `march7-v14-makeup-preview.blend`。纹理已经嵌入文件。默认显示带妆的光头，方便观察脸雕；如果视窗看不到颜色，按 Z 后选择「材质预览」。

右上角 Outliner 中的集合：

- `01_V14_Painted_Head`：v14 主壳与后盖，仅新增材质、UV 和颜色遮罩。
- `02_Character_Eyes_Brows_Mouth_PREVIEW_ONLY`：原角色眼部、眉睫和口部视觉附件。
- `03_Optional_Original_Hair_PREVIEW_ONLY`：原角色头发和头饰，默认关闭。打开这一集合的视窗与渲染可见性即可显示。
- `90_Original_March7_Reference`：完整的原角色头部参考，默认关闭。对照时应先关闭前面三个集合，避免两个头重叠。

## 查看图片

- `makeup-multiview.png`：带妆光头的正面、左前斜侧、右前斜侧和纯侧面。
- `hair-multiview.png`：加入原发型后的三个角度。
- `character-comparison.png`：左 v14、右原角色，同相机、尺度和灯光的正面及斜侧对照。
- `previews`：各视角完整 PNG。

所有图片由三维模型渲染，拼图仅作缩放与排版。妆面使用原脸部贴图，通过 UV 转移贴合 v14 表皮；新增颅皮过渡到匹配肤色。没有用生成图或图片修形改变头壳。为便于看配色，材质将柔和受光与原贴图自发光显示混合；不是游戏引擎截图，也不是实物妆面的颜色校准照。

## 预览范围

眼睛是原模型的眼白、虹膜和高光视觉表面，眉睫也是独立视觉网格。眉毛单独细分贴合头壳，少量睫毛顶点向外贴合，避免悬浮或被实体表皮遮挡；主头壳没有移动。头发保留原角色几何，供判断整体神态。

这些附件不代表可直接打印的 16 mm 眼珠、睫毛或假发结构，也不保证商业眼珠装好后的虹膜大小和神态完全相同。结构打印继续使用相邻 `march7-bjd-1-4-v0.14` 中的配套 STL。

`preview-build-report.json` 校验另存再打开后的主壳/后盖坐标与三角哈希一致；`render-provenance.json` 记录渲染输入和相机；`unpainted-baseline-integrity.json` 记录旧版交付文件完整性。这里是外观预览，未重新执行已不受本轮影响的结构测试。

原资产为用户已下载的本地模型，使用说明保留在 `source-usage-rules.txt`。
