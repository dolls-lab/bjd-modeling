# 三月七四分 BJD · v0.6 耳后侧脑体量修整

用户指出 v5 耳朵后面的新增脑壳比耳前侧面鼓出一块。本版以 v5 为基线，按原三月七脸侧的宽度收回新增侧脑，使耳前、耳后的侧面接近同一连续曲面。原脸与耳廓来源于本地三月七 PMX；未缩放五官来补偿头围。

## 文件与单位

- march7-bjd-head-v0.6-draft.blend：编辑与查看用场景。
- march7-head-shell-v0.6-draft.stl：空心头壳。
- march7-head-cap-v0.6-draft.stl：可拆后脑盖。
- preview-*.png：实际模型渲染及 v5/v6 同角度对比。
- validation.json、source-preservation-review.json、side-shell-review.json：网格、原面雕保护及侧脑截面检查。

STL 数值单位是 **mm**，Blender 场景单位比例为 0.001。只打印两个 PRINT 对象；隐藏 master、源角色参考和 baseline 文件用于编辑与核对。

## 修整与保护范围

原脸侧面在不包含耳廓的前侧区域取样，作为后侧脑的宽度参考。新增脑壳只收回超出的体量，原脸、耳廓和闭嘴等已有补片通过真实网格来源保护。侧脑上下端和后侧采用连续过渡。

打印件内腔允许随外壳移动。使用同一 YZ 位置的侧向位移传到内外壁，避免最近表面投影跨高度时取到不同位移、造成薄壁。保护报告把“可见面雕未改变”与“内腔可变形”分列；没有把原内壁的改变说成完全零位移。

后脑盖、磁铁孔、定位机构和颈部配合区保留。各项实际零位移及当前文件 SHA 以审计报告为准。

## 尺寸与打样

原 190 mm 头围是最初选用的打样参考，并非用户指定的精确尺寸。本次按要求收回侧脑体量，保留原角色脸部尺度，指定水平截面的实测头围为 **186.45 mm**（v5 为188.14 mm）；该报告也保留与历史 190 mm 参考的差值，未把它误写为仍满足190±2 mm。

使用 16 mm 球眼，目标搭配 UFdoll 四分囡囡体。23 mm 球面颈座、7×14 mm 拉筋槽以及五金间隙为试版设计参数，尚未取得原厂精确接口或实物验证。名义壁厚 2.6 mm；侧脑修整后的抽样壁厚另列检查，抽样不等于全表面最小厚度保证。

本版侧脑指定区域1950条横向射线抽样最薄约2.424 mm；眼洞与v5在0.05 mm投影网格下相同，16 mm球眼的后口装入路径通过。可见原面雕、原耳、颈部、磁铁区和头盖的独立保护审计通过。耳上衔接另有局部曲面平顺处理，范围和最大位移见 upper-junction-report.json。

**本版仍需实物打印与试装。** 数字检查不能验证材料收缩、拉筋强度、眼泥/眼柄空间或磁铁胶层。

## 复现与来源

build_head.py 使用目录内 v5 基线、来源保护数据和目标曲面数据生成 v6。保护数据重建步骤见 SOURCE_AUDIT.md。参数中的原 PMX 路径是当前机器的本地来源，换机器核对来源时需更新。

计算与检查依赖 Blender 4.5、numpy、scipy、trimesh、manifold3d、Pillow；模型使用限制见 source-usage-rules.txt。原模型版权 miHoYo、编辑神帝宇，原说明允许改造但限制商业使用及二次配布。本次仅本地保存。
