# 三月七四分 BJD 头壳 · v0.7 打样版

本版在交付的 v0.6 上修顺耳根后侧至侧脑壳的局部连接。保留两眼洞、颈口和后开式头盖。所有 STL 的数值单位为毫米。

## 文件

- `march7-bjd-head-v0.7-draft.blend`：最终可编辑打印网格、头盖，以及隐藏的原角色脸部与 v6 外表面参考。
- `march7-head-shell-v0.7-draft.stl`：更新后的空心头壳。
- `march7-head-cap-v0.7-draft.stl`：与 v6 完全相同的后头盖。
- `ear-rear-comparison.png`、`ear-front-comparison.png`、`side-comparison.png`：同相机、同灯光的 v6 / v7 对比。原始截图在 `side-views/`。
- `validation.json`：实际导出 STL 的闭合性、连通性、头盖装配及开口检查。
- `source-preservation-review.json`：三月七面雕、耳前与耳廓边界、受控耳背微修及机械区域的顶点审计，以及 Blender / STL 对应性核查。
- `local-fairing-report.json`、`local-quality-review.json`：局部修顺参数与耳根质量检查。

## 本次调整

v6 从外表面向打印头壳传递侧向变形时，在固定耳缘与移动脑壳之间出现突变，少量长窄三角形形成耳后棱纹。本版直接对打印头壳的局部曲面求平滑过渡，把原面雕及接口作为求解边界。没有再次整体缩放或套用椭球头型。

原有脸部、五官、下颌、耳前及耳廓边界保持原坐标。耳背内部另做一次小范围整理：依据原模型耳背 UV 分区选定 442 个内部点，保留距离几何边界至少 0.5 mm 的保护带，最大移动约 0.124 mm。目的是柔化耳背边缘附近的细小凹点，同时保留角色耳形。原角色脸部自身的细小表面起伏仍可能在强侧光下可见。

Blender 中的 `PRINT_01_Head_Shell` 是最终 v7 可编辑头壳。隐藏的 `EDITABLE_Outer_Surface_Before_Hollowing` 保留 v6 的挖空前参考，带有版本说明，不能当作 v7 最终表面直接重新挖空导出。

## 尺寸与适配

维持此前四分打样比例、16 mm 装眼设计及 UFdoll 四分囡囡体颈部参考。颈座、磁铁孔和头盖接口不变。头围为约 18.65 cm，具体本版截面测量见 `validation.json`；早期 19 cm 是初始设计参考，未为凑数而缩放原面雕。

数字网格与装配检查不等于实物适配。尚未打印试装；材料收缩、眼球品牌、磁铁实测与实际娃体颈座配合需用打样确认。
