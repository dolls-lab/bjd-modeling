# 三月七四分 BJD 头壳 v13：眼角至耳根表面细修

已完成最终几何、保护范围和导出一致性检查。未进行实物打印或试装。

本版以用户已接受的 v12 实际打印模型为基础，仅修顺左右外眼角到耳根之间的太阳穴皮肤，以及耳上根周围的短沟和坑洼。保留原有圆弧和自然耳根凹陷，没有重新构造头型、空心壳、后盖或安装结构。

局部实际最大位移约 0.3202 mm，共修改 17,623 个皮肤顶点；头部 X/Y/Z 包围盒尺寸完全不变。修坑会改变局部表皮位置，因此不声称所有方向的每一个轮廓像素都完全相同。最终多视角轮廓差异见 `silhouette-review.json`。

眼缘保护带、主要五官、耳廓、v12 已完成的耳背细修、内壁、后盖和修改范围外的顶点均保持原位。隐藏母面仍为此前的重建参考，最终表面在 `PRINT_01_Head_Shell`；不能用隐藏母面代替本版精修件。

## 打开与文件

- 使用 Blender 的「文件 → 打开」选择 `march7-bjd-head-v0.13-draft.blend`。
- `PRINT_01_Head_Shell` 是主头壳，`PRINT_02_Removable_Cap` 是后盖。
- 配套 STL 为 `march7-head-shell-v0.13-draft.stl` 和 `march7-head-cap-v0.13-draft.stl`，约定单位为毫米。后盖与 v12 字节相同。
- `surface-detail-comparison.png` 为三张局部前后对比，左 v12、右 v13。`whole-head-comparison.png` 为整体侧面及俯视对比。
- 图片由实际打印对象渲染，相机、尺度和灯光一致，只作缩放排版，没有用图像修形掩盖网格。

## 数字验证

最终报告均绑定本版模型哈希。`surface-only-review.json` 核对局部范围外与其他对象不变、内外壁归属、Blend 与 STL 的几何一致性；`print-intersection-check.json` 检查非相邻三角交叉；`face-opening-comparison.json` 比较眼洞；局部壁厚与多视角轮廓单独记录。

实际 STL 未发现非相邻三角自交、退化或重复面；与 Blender 打印对象的有向三角一致。眼洞在 0.05 mm 采样下与 v12 逐像素相同。九个整体视角的外轮廓最大栅格差异为 0.1 mm，左右纯侧面为 0；测量本身的差值分辨界限约为 0.1 mm。这是指定视角核对，不是所有方向的严格零位移证明。

局部壁厚也会随表皮修整改变。3,000 个同位置射线样本的最小值由约 0.706 mm 变为 0.730 mm，中位数由 2.601 mm 变为 2.579 mm；眼外角低位附近有 19 个样本从略大于 1 mm 降到约 0.97–1 mm。原本的薄眼边与普通颅壳应分开理解，不能声称本版处处为 2.6 mm 壁厚，也不能把射线样本当成全表面最低厚度或打印强度保证。详细位置与配对结果见 `side-shell-review.json`。

v12 的机械结构是本版基线，本轮没有重新空心化或改变内部安装结构。已证明不变的部分沿用上一版结构设计；机械装配和 16 mm 球形装眼的历史检查沿用依据见 `inherited-functional-checks.json`，没有冒充本轮重新执行。尚未实物打印、试装或验证树脂收缩与强度。

## 复现

`surface-postprocess/print-solution.npz` 保存完整处理前后坐标、拓扑和保护选区；`surface-postprocess/solve.py` 为局部求解，`apply_surface_finish.py` 从 v12 基线应用获选结果并导出本版。处理采用局部最小弯曲平滑和渐变边界，没有全头重网格化。

复现应在副本目录中进行，并保留匹配哈希的 v12 基线。脚本会核对基线坐标和拓扑；不要对已完成的 v13 再次套用位移。部分审查脚本需要本机既有 v12 文件、Python 科学计算依赖或 Blender，交付的最终 Blend/STL 可直接打开，无需重跑这些脚本。
