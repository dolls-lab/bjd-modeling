# 三月七四分 BJD 头壳 · v0.3 面部曲面修整版

基于 v0.2 后脑开盖版，修整实际三维外表面上的额头接面、脸颊与下巴细纹。使用局部二次曲面拟合，按毫米邻域处理起伏，降低普通反复平滑引起的收缩；通过权重保护眼缘、鼻唇和耳廓。预览使用与 v0.2 相同的相机、材质和灯光，不使用图片磨皮。

分件仍为带两眼洞、颈口的空心主体与磁吸后脑盖。脸、耳和颈座留在主体，后盖向后略向上取下。旧版文件独立保留。`preview-comparison.png` 为相同角度的修改前后对照。

## 文件与使用

- `march7-bjd-head-v0.3-draft.blend`：可编辑 Blender 场景，包含两件打印网格、隐藏的原始脸参考和完整外表面。
- `march7-head-shell-v0.3-draft.stl`、`march7-head-cap-v0.3-draft.stl`：主体、后脑盖。
- `parameters.json`、`build_head.py`、`parse_pmx.py`：参数和完整重建脚本。
- `build-report.json`：实际平滑位移、尺寸、分缝和五金位置。
- `validation.json`、`validate_mesh.py`：独立 STL 网格、分件、头围、孔洞和球眼检查。
- `eye-insertion-check.json`、`check_eye_insertion.py`：从后开口到眼窝的连续球体扫掠检查。
- `face-opening-comparison.json`：前版与新版最终 STL 眼孔的射线投影对比。
- `preview-*.png`：模型实渲染与对照图。

STL 数值单位为 **mm**。Blender 场景单位比例为 0.001；导入切片软件按 mm，勿再放大 1000 倍。只导出 `PRINT_01_Head_Shell` 与 `PRINT_02_Removable_Cap`，隐藏参考对象不属于打印件。

更改参数后，以 Blender 4.5 重建并重新验证：

```sh
blender --background --factory-startup -t 4 --python build_head.py
python validate_mesh.py --check-eye-clearance
python check_eye_insertion.py
```

验证脚本依赖 numpy、trimesh、manifold3d；参数中原 PMX 路径须指向本机已有文件。头围、眼珠和五金尺寸单独设定。

## 尺寸与装配

- 头围设计目标约 190 mm；眼珠 16 mm；目标娃体 UFdoll 四分囡囡体。尺寸参考沿用 [DOLK 商品表格](https://dolk.jp/portal/itemDetail/?ItmID=215136) 的头围 190 mm、颈围 66 mm、假发 7–8 英寸，并非用户实物测量。
- 23 mm 球面颈座和 7 × 14 mm 拉筋/S 钩槽属于可调打样假设，**不是 UFdoll 原厂接口尺寸**。
- 壳体名义厚度 2.6 mm，眼窝和承力区另行处理；这不代表完整表面最小壁厚保证。
- 配四颗 4 × 2 mm 磁铁，每件两颗；槽径 4.25 mm、深 2.2 mm。上沿有 Ø4 mm 定位柱与 Ø4.5 mm 盲孔。
- 眼珠先从后开口中央送入，再向左右眼窝移动，避免直接斜插。装眼后核对眼泥空间、眼角贴合与视线；粘接磁铁前确认极性。

两件显示姿态沿拆盖方向留 0.25 mm 间隔；验证也检查后盖向内平移至接触的姿态。分缝采用 `Y + 0.3 Z = 29.5 mm`；X 左右、Y 向后、Z 向上。

## 验证边界

本次两件网格、分件和球眼检查通过，指定截面头围约 **189.566 mm**。与 v0.2 在同一坐标的 0.05 mm 射线投影网格下比较，两只眼洞的宽、高、面积和中心均未检测到变化；这不是连续曲面绝对零位移的证明。两颗 16 mm 球眼经中央进入后转向眼窝的连续扫掠检查通过，最小数字间隙约 0.187 mm。

验证结果与导出 STL 的 SHA-256 绑定。检查闭合、单连通、绕序、体积、非流形/重复/退化面、后盖与主体的碰撞、拆盖方向的多个位置、16 mm 球眼和安装路径，以及原脸/耳/颈台留在主体。

倾斜接缝的 STL 浮点误差单独按接触平面容差分类，原始交集体积保留。头围以指定截面的真实外轮廓度量，仅在二维测量时闭合 0.00001 mm 精度微隙；网格未作这种修复。实际软尺的拉紧路径可能跨过凹面，所以不必与表面周长完全一致。

**尚未实物打印、装眼、粘磁铁或接娃体试装。** 数字球眼不包含眼柄、凸虹膜、眼泥或工具；打印收缩、材料强度与 UFdoll 颈球匹配仍需打样验证。切片不得自动封住眼洞、颈口和后盖开口。
