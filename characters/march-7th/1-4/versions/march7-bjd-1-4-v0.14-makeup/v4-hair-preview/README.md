# 浅肤色 v14 头壳＋原三月七发型预览

使用 Blender 打开 `march7-v14-pale-skin-original-hair.blend`，选择「材质预览」或「渲染」查看。

在 v3 浅肤色模型上，仅追加原三月七模型的发型和耳旁发饰。保持原坐标、原比例、原 UV 和贴图；没有导入原角色的脸、眉睫、嘴或游戏眼片。当前头壳、后盖、两个预览眼杯、浅肤色和局部妆面保持原样，v3 文件未覆盖。

`04_Original_March7_Hair_PREVIEW_ONLY` 集合控制头发和发饰，关闭它可查看无发型的头壳。头发只用作观感参考，不是已验证可制作的假发模型。纹理已打包在 Blend 文件中，可直接打开。

`original-hair-multiview.png` 展示正面、左右斜侧和侧面；`original-hair-face-closeups.png` 展示两张面部近景。`previews` 中是六张独立原图。所有图片均从本模型实际渲染，只缩放排版，没有修图。

`hair-preview-report.json` 记录保存重新打开后的网格/UV一致性，`render-provenance.json` 记录六个镜头。原材质在 Blender 中使用原图颜色、透明度及部分棚灯着色，并非游戏原渲染器。原素材使用限制见上级 `source-usage-rules.txt`。
