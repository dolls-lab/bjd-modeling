# 当前浅肤色 BJD 与原三月七模型对照

所有图板左侧是当前 v14 BJD（浅肤色、局部妆面、预览眼杯、原发型），右侧是本地原三月七 PMX 的头部模型。相机位置、正交尺度、灯光、背景和色彩管理一致；两侧使用同一份原发型和发饰。

- `overall-comparison.png`：正面和左前斜侧整体对照。
- `face-comparison.png`：正面和斜侧面部近景。
- `profile-comparison.png`：侧面轮廓。

原模型保留原网格、UV、贴图、diffuse 乘色、透明度和法线；显示原眉睫、眼片、嘴部与上眼部半透明阴影片，不使用可选表情覆盖层。为便于在同一棚灯下观察，原脸与眼部使用与 BJD 对应部位一致的 Principled 表面参数，关闭参考文件的自发光颜色预览；原发型材质与当前 BJD 完全相同。

这是原 PMX 在 Blender 中的重渲染，不是游戏实机截图，也没有复现官方游戏的 toon 着色。因此颜色、反光和阴影差异应结合材质与原模型法线理解，不能单凭它们判断雕刻误差。没有修图、拉伸或重新拟合模型比例。

原模型只在渲染进程内临时载入，没有写回任何 Blend。当前 BJD 图片复用前一步同版文件的实模截图，并核对模型、图片哈希和镜头参数；原模型按这些镜头重新渲染。详见 `comparison-provenance.json`。本文件夹不会替换当前的娃头或妆面模型。
