# 三月七四分 v30：S 钩穿入、提起、转向后落槽

[Blender 模型](march7-bjd-head-1-4-v30.blend) · [主头壳 STL](march7-head-shell-1-4-v30.stl) · [后盖 STL](march7-head-cap-1-4-v30.stl)

本版按用户明确的装配方式重新设计：**已连绳的 S 钩从颈口穿进头内 → 提起 → 转 90° → 横着落入中槽**。此前在头内挂钩后落座的假设不适用于本要求；旧版静态或提拉检查不能证明这条完整安装路径通过。用户已确认本轮先使用现有约 **30 × 18 × 2.3 mm** 的参考 S 钩，曲线仍为近似形状。

![穿入转向结构总览](../../../reviews/pass-turn-lock-2026-11-14/pass-turn-overview.png)

圆端贯通孔设计短边 X × 长边 Y 为 **7.6 × 19.2 mm**，从原下方颈口贯通至新承托台，孔沿一起调整。长边大于参考钩的 18 mm 外宽，供钩宽面对齐穿入；短边小于钩外宽，使钩转横后跨在两侧实体肩上。仅比较长宽还不足以证明可安装和防脱，必须核验完整钩、所连绳环及整个运动过程。

三道横槽的长度不再随分制缩放：三版统一在 **X = ±6 mm** 内保留长度方向完整深度权重，向外以五次函数逐渐变浅，到 **±7.5 mm** 退到零，总影响长度 **15 mm**。槽宽 **4 mm**、最大设计深度 **0.8 mm**，前中后 Y 位置保持 -5.600, 0.000, 5.600 mm。槽的实际深度仍受横截面、孔口和低台面淡出影响；中槽应让下弯跨两肩并在落座后提供抗转。

承托台继续采用大半径浅球面，基础球面半径 **30.00 mm**、足迹半径 **13.50 mm**。**本轮扩大了原下方颈孔，局部切除了孔附近的球窝表面**，不能再说球窝或下孔完全不变。最终审核确认切孔范围外的球窝、外部头型和面雕、磁铁座与后盖受保护。按原模型实际上半球窝表面、3° × 5° 角步长采样，估计保留 **271.29 mm²（81.84%）**；原采样域面积约 331.49 mm²。该比例不代表整个球窝，也不是强度或娃体适配证明。

模型已保存重开，头壳与后盖通过水密、单一连通件及 Blender／STL 网格一致检查。最终 STL 的完整钩绳路径装配及独立审核均已通过，入口保守扫掠最小净隙约 **0.400 mm**；相对落座姿态上提 **2.5 mm** 后转向。保存的 Blender 参考钩绳对象也已独立读回，与运动验证使用的几何吻合。连续路径检查包括：入口的投影棱柱覆盖；钩和绳同步旋转的最小净隙与角步长位移界；钩、绳分别用相邻端点凸包覆盖下降段；最后核验下弯左右承托、横向不能直落、落座抗转以及提起后的反向拆卸路径。

落座姿态保留 0.002 mm 数值避碰间隙；下压 0.08 mm 探测确认下弯在中槽两肩承托。指定向下探测与原位 ±10°、±15° 试转均出现几何阻挡，反向拆卸采用已通过的提起、转回及退出路径；这不是摩擦或弹力受载试验。

本轮仅验证中槽，前后槽仍为预留。参考绳径 **2.2 mm**，刚性包络随钩运动，不模拟弹力绳材料、摩擦或受力；真实钩形、柔性绳路、娃体适配和打印承载尚未验证。测试的是头壳与参考钩绳的相对运动，不把假设实心的娃体球头作为穿钩对象。运动时后盖可打开，最终落座姿态另检查闭盖。

本轮直接基于 `1-4/versions/v20-magnet-seats` 构建。`parameters.json` 的 `through_slot_width_mm` / `through_slot_length_mm` 定义新贯通孔；旧 `neck_slot_*` 字段记录来源尺寸，不是本版现有孔口。用 Blender 打开 `.blend`，隐藏 `PRINT_02_Removable_Cap` 查看内部；`REFERENCE_ONLY__NOT_FOR_PRINT` 中的参考钩和绳不导出打印，打印只使用主头壳与后盖 STL。
