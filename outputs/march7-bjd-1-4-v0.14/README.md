# 三月七四分 BJD 头壳 v14：眼洞还原、正顶微加宽

已完成本版数字几何核对和多角度实模渲染。仍为待实物试打、试装的设计稿。

以 v13 实际打印件为基础，按原三月七 PMX 的眼洞轮廓修正眼缘及内侧孔壁，并只沿横向稍微加宽高位头顶。保持头部高度与面部宽度，保留之前完成的耳前、耳后表面细修。

## 打开文件

使用 Blender「文件 → 打开」打开 `march7-bjd-head-v0.14-draft.blend`。

- `PRINT_01_Head_Shell`：本版主头壳。
- `PRINT_02_Removable_Cap`：本版配套后盖。
- 两个同版本 STL 约定单位为毫米。头顶和后盖同步变宽，请配套使用 v14 主壳与后盖。
- 隐藏的原模型与历史母面只作参考；最终制作结果以两个 `PRINT_` 对象为准。

`shape-and-eyes-comparison.png` 是眼洞与正顶前后对比，左 v13、右 v14。`whole-head-comparison.png` 是前斜侧、侧面和俯视对比。所有图片由实际打印网格以相同相机和灯光渲染，仅作缩放排版。

## 数字验证

头部总高保持 **69.7151 mm**，最高点坐标保持 Z = **69.7844 mm**。脸部 Z = 5–45 mm 的九条正面宽度截线完全不变，鼻、嘴、下巴、耳朵与眼部修改范围之外的低位面部顶点保持原位。冠顶只沿 X 方向加宽，最大单侧移动 **1.1533 mm**；Z = 60 mm 处总宽由 **36.4830 mm** 变为 **38.6288 mm**。后盖随顶部同步修改，磁铁孔、定位销/孔及颈部安装区域保持原坐标。

原 PMX 与最终打印件使用相同固定比例、相同坐标与正面射线比较，没有另行拟合。0.05 mm 采样下，两眼开口与原模型重合度为 **99.68% / 99.69%**，单眼高均为 **9.30 mm**，宽 **11.45 mm**，原模型为 **11.50 mm**；采样边界最大差 **0.05 mm**。这些是正面有效开口的二维测量，内孔壁经过实体头壳适配，并不声称全部三维眼缘逐点等同原模型。详见 `eye-review/eye-original-comparison.png` 与同名 JSON。

最终 Blend 与两个 STL 的有向三角完全一致。网格封闭、拓扑、装配和后盖退出位置检查通过；装配设计间隙测得约 **0.24986 mm**。后盖完全压到接缝平面时出现约 **0.000133 mm³** 的浮点精度接触薄片，所有交叠点到接缝面的距离小于 **0.00000215 mm**，报告保留原始数值并按严格共面条件分类。16 mm 球形眼珠终点检查与从后开口经中央中转的连续装入路径检查均通过，包络球与头壳的最小数字间隙约 **0.18045 mm**；详见 `eye-review/eye-insertion-check.json`。全头与全盖的非邻接三角检测未发现交叉、疑似接触、退化或重复面；共享顶点的邻接面排除规则见 `print-intersection-check.json`。

眼缘局部仍较薄。配对法向射线抽查中，修改眼区的最短有效弦长从约 **0.537 mm** 变为 **0.514 mm**；其中 45 个有效配对样本新降到 0.6 mm 以下。这是圆缘与孔壁上的局部弦长筛查，包含射线命中位置变化，并非全局最低壁厚或打印强度保证。不能把 2.6 mm 名义壳厚理解为每处厚度。具体点位和配对命中位置保存在 `eye-review/eye-wall-chord-review.json`。

冠顶普通外壳的配对射线样本中，主壳/后盖最短弦长约为 **2.597 / 2.600 mm**；本次加宽没有新增低于 0.6 mm 的冠顶配对样本。后盖内部机械附近存在继承的约 **0.337 mm** 短弦，本版基本不变。接缝短弦与无明确对壁命中的射线单列，有限抽样不代表全表面最低厚度保证，详见 `crown-wall-review.json`。

`preservation-report.json` 核对高度、脸宽、保护区域与导出一致性；`validation.json` 核对两件拓扑、装配与孔口；`previous-version-integrity.json` 确认上一版交付的 60 个文件未变。

## 复现与数据

`apply_shape_and_eyes.py` 从同级 v13 Blend 应用获选眼部与冠顶坐标，保存最终模型；`final-change-solution.npz` 记录前后坐标、拓扑及改动范围。获选局部结果分别位于 `eye-postprocess` 与 `crown-postprocess`。应用时需要保持哈希一致的 v13 基线；从头重求还需要本机原 PMX、历史诊断输入和相应 Python/Blender 环境。交付的 Blend/STL 可直接打开，无需重跑脚本。

原角色 PMX 未收入交付包，使用限制见 `source-usage-rules.txt`。实物打印、树脂收缩、磁铁/颈口/眼珠试装尚未验证。
