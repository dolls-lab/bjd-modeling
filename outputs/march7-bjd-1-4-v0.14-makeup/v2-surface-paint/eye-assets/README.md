# 最终球面眼预览组件

在 Blender 中导入本目录 `build_hemisphere_eyes.py`，调用 `objects, report = build_eyes(collection)`。默认输入已选定为 **R9 主体＋局部皮肤避让**，几何 NPZ SHA 为 `e4f9c4f6d07d078dbe21501327b0ee76a4c82b7bdf3583d7377f85a546c19297`。

两个开背眼杯的主体外半径为 9 mm、内半径 8.4 mm；相对原眼座分别向鼻侧移动 1.5 mm、向前移动 2 mm。中心为 `[±12.163962920147602, −15.289332231246028, 27.67311677124019]` mm，朝向 −Y。杯后方只有环形口，不使用平圆盘封住背腔。

为保留头壳的眼睑妆线，只把会盖住实际前脸皮肤的眼杯边缘沿 +Y 退到皮肤后 0.35 mm，并平滑过渡；对应内杯点同步移动。最大局部回退约 1.60 mm。局部回退场额外使用三圈邻域包络和高斯平顺，消除眼白边缘条纹反光，并保留原避让余量。X/Z、虹膜图案位置和尺寸均不变。主体仍为球面，隐藏边缘经过适配，因此**不是处处严格的数学半球**。

原三月七虹膜、瞳孔和白色高光均烘焙在球面贴图上。函数不会创建或显示原游戏眼白、虹膜或阴影片；PNG 加载时自动 pack。外侧使用普通 Principled 光泽材质，emission=0，内侧为白色。

本组件只服务于妆面和相似度观察，不是可直接制造的眼珠，也不声称与头壳物理无交叠。原 R8 组件虽然正面覆盖、无碰撞，但斜视有明显漏空；它的旧文件和检查报告已移到 `baseline-r8/`，不能作为当前最终组件的通过依据。R9 未退让候选的交叠数字也不能代替最终退让后的检查。最终选型以实际前视、斜视及内部渲染审查为依据。

`eye-assets-report.json` 记录最终局部退让方法、数量和未动头壳的事实；`selected-eye-assets.json` 记录默认文件哈希。此次提升仅复制已选文件，没有重新求解几何。所有 v14 头壳、头盖及原始源文件保持不动。

制作链保留在本地：

1. `baseline-r8/prepare_eye_assets.py`：原虹膜烘焙和基础 R8 杯。
2. `candidate-fit/make_candidate.py`：R9 主体及位置调整，输入明确指向 `baseline-r8/`。
3. `candidate-fit-protected/protect_face_skin.py`：Blender 中对实际前脸首个可见表皮做局部眼面退让；依赖上一步数组及 `../../../uv-transfer/face-uv-transfer.npz` 的源外皮对应信息。

上述脚本输出各自工作目录，默认交付文件不会被自动覆盖。若需要打包完整制作链，应同时保留这四个目录和源参考/UV 数据；仅使用最终预览则只需本目录默认 helper、NPZ 和两张 PNG。

4. `candidate-fit-smooth/smooth_eye_edge.py`：平顺回退场，保留眼缘保护余量；此步骤为最终选择。
