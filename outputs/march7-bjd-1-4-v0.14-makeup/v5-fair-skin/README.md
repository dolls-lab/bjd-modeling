# 三月七 v14 妆面预览 v5：进一步调白肤色

用 Blender 打开 `march7-v14-fair-skin-original-hair.blend`，选择「材质预览」或「渲染」。原发型和发饰已保留；可隐藏 `04_Original_March7_Hair_PREVIEW_ONLY` 集合查看无发型头壳。

模型所需贴图已打包在 `.blend` 内，可独立打开。此目录保存最终模型、预览图和核对记录；两个 Python 脚本保留制作过程，重新运行需要本地上一版 `../v4-hair-preview/` 及其中的原模型对比素材，这些中间版本未纳入本次提交。

本版将主头壳和后盖的统一肤色由 `#F2D5CA` 调为 **`#FAE8E3`（sRGB 250,232,227）**。之前取样的额头底色比原模型多数无妆脸颊、鼻侧和下颌更暖；新颜色取自这些面部区域的主色，增加明亮度并减轻偏黄感。原纹理选定前脸采样区域的 66 个顶点中，50 个为该色，其余主要位于轻微腮红处。

只改统一材质底色，不增加整脸贴图或覆盖网格。头壳、后盖、眼杯、原发型及发饰的网格和 UV 不变；局部眉眼嘴妆、眼睛与头发贴图、材质其他设置、灯光、曝光均保留上一版。原 v4 文件未覆盖。

`skin-tone-comparison.png` 按「上一版／本次调白／原模型」排列正面、斜侧近景；`new-original-overall.png` 是本次 BJD 与原模型的整体对照。图片使用与上一版完全相同的镜头和灯光，没有修图。右侧原模型是本地 PMX 的 Blender 重渲染，并非游戏实机截图。

`skin-tone.json` 记录颜色与采样依据，`skin-change-report.json` 记录保存重开后的网格、UV、贴图一致性，`render-provenance.json` 记录渲染镜头。眼杯和发型仍仅作观感预览，打印件使用原 v14 的主壳、后盖 STL。
