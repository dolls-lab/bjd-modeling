# 三月七 v14：局部妆面＋半球眼预览 v2

用 Blender 打开 `march7-v14-local-makeup-v2.blend`，切换「材质预览」或「渲染」即可查看。

这是从已确认的 v14 素头另存的新模型。主头壳和后盖的顶点、拓扑、位置保持一致；原素头文件不覆盖。

- 眉毛、眼线、眼褶线和嘴线直接作为透明底局部颜色贴图作用于原头壳表面，没有整张脸的肤色贴图，也没有覆盖面部的网格。未上妆区域继续使用原素头树脂材质。
- 两个眼睛以开背半球为主体，朝向眼洞；三月七虹膜、瞳孔和高光颜色画在曲面上，未使用原角色的眼睛平片。眼杯边缘作局部退让，让眼白留在原眼睑妆线后方。
- 保持原面雕，不使用妆面位移、浮雕或修改器改变头壳形状。

## 在 Blender 中查看

`01_V14_Head_Local_Paint` 中是主头壳和后盖；`02_Two_Hemisphere_Eyes_PREVIEW_ONLY` 中是两只可单独隐藏的半球眼。

隐藏 `PRINT_02_Removable_Cap` 后，从背面可看见眼杯。主头壳材质中将 `LOCAL_MAKEUP_ON` 设为 `0` 可以关闭局部妆面；设为 `1` 恢复。眼睛单独隐藏即可查看完整素头。查看器的「实体」模式默认不显示贴图，需要使用「材质预览」或「渲染」。

`local-makeup-multiview.png` 是四个角度；`surface-and-interior.png` 对照同一头壳上色前后，并展示内部半球结构。图片均来自本文件的实际三维渲染，只作缩放排版。

## 文件与验证

`preview-build-report.json` 记录保存并重新打开后的主壳、后盖几何指纹；`render-provenance.json` 记录渲染输入文件和相机。`paint-assets` 保存透明底局部妆面及来源映射；`eye-assets` 保存半球构建脚本、纹理与检查结果。

这是观感预览，适配眼杯仅用于模拟装眼效果，不是已验证可打印、可装配的眼珠设计；局部退让后的眼杯不再是严格数学半球，也没有沿用早期 16 mm 球体的无碰撞结论。打印文件仍使用同级 v14 目录的主壳与后盖 STL。原角色素材的使用范围见上级 `source-usage-rules.txt`。
