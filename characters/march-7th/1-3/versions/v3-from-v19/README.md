# 三月七三分 v3 · 基于四分 v19

面部和头型直接取自已确认的四分 v19，整体等比放大 **1.25 倍**，再单独适配三分颈部接口。嘴唇、嘴角、脸颊及其他面部细节随 v19 一起等比放大。本版保持空心头壳、两眼洞、可拆后盖和颈口结构。

尚未选择娃体，颈围 90 mm 仅是沿用的设计参考，不能等同于颈座直径或实测适配。颈座、槽口、顶板等参数可通过脚本调整；当前构建采用局部减料方式，因此接口不得小于等比缩放后的源模型孔腔。若需要更小接口，应另行设计内衬或局部重建。改变整体倍率时也需配套检查接口参数。

## 形状保护与验证

实际 STL 独立核验通过。除颈部支承范围外，面部、耳朵和头型与四分 v19 等比放大后的双向顶点最大误差为 **0.00000427 mm**；整个后盖为 **0.00000429 mm**，属于 STL 坐标精度。

颈部修改限制在底部局部区域。32 mm 球面支承和槽口通过射线测量，槽口实测约 9 × 18.00000047 mm。31.5 mm 保守包围球与颈座无交叠，最小清隙约 0.235 mm；20 mm 保守眼球包围体在预设位置也无交叠。

主壳、后盖均闭合且法向一致。装配姿态及离散开盖路径检查通过；这些数字检查不能代替实物打印、材料强度、眼珠安装路线或娃体试装。低仰角开口处没有命中的射线被记录为未测，不作为球面支承通过的证据。

已保存并重新打开 Blender 文件核对网格。四分 v18/v19 和旧三分 v1/v2 共 139 个历史文件保持原字节，见 [源文件保护记录](source-integrity-after.json)。四分 v19 的接口沿用旧版几何；历史接口坐标来源及哈希单独记录在 [接口参考](source-interface-reference.json)，头部网格只从 v19 读取。

## 使用和重建

用 Blender 的“文件 → 打开”选择 `.blend`。STL 数值按毫米使用，导入切片软件时选择 mm。

```sh
blender --background --python build_model.py
python3 validate_model.py
```

Blender 4.5.9；验证需要 NumPy、SciPy、trimesh、manifold3d。来源使用说明随模型保留于 [source-usage-rules.txt](source-usage-rules.txt)。
