# 三月七四分 BJD 头壳 · v0.8 打样版

本版落实新的形状要求：整体是圆润的头型，表面与连接处顺滑。修改集中在侧颅、耳后到后脑的连续弧面；三月七面雕与 v7 耳朵保持原坐标。

## 调整内容

v6/v7 的侧向限宽使部分耳后截面趋于直线，低处还略有内凹。本版取消这种平面目标，以此前较完整的颅骨曲面作为体量参考，在最终空心头壳上求平滑过渡。使用截面的外凸弧度、转向和多角度真实渲染检查形状，没有套用整体球形或椭球形来改变脸部。

原脸部、全部可见耳廓（包括 v7 已微修的耳背）、颈部接口、磁铁位置与后开头盖均相对 v7 固定。内外壳一起参与局部调整，并复核壁厚方向采样。

## 文件

- `march7-bjd-head-v0.8-draft.blend`：最终可编辑头壳、后盖与隐藏源参考。
- `march7-head-shell-v0.8-draft.stl`、`march7-head-cap-v0.8-draft.stl`：毫米单位的打印零件。
- `roundness-comparison.png`：v7/v8 同光照的头型与俯视轮廓对比。
- `surface-comparison.png`：耳后近景与正面对比。
- `side-views/`：最终版本多角度图。
- `validation.json`、`source-preservation-review.json`、`local-quality-review.json`：数字结构、面雕/接口保护及局部曲面检查。

Blender 中 `PRINT_01_Head_Shell` 是最终 v8 网格。隐藏的 `EDITABLE_Outer_Surface_Before_Hollowing` 仍是 v6 挖空前参考，不包含 v7/v8 在打印网格上的后续整理，不应将它当作最终表面重新挖空导出。

## 尺寸与适配

维持此前四分比例及 16 mm 装眼设计。实际头围由最终截面测量记录于 `validation.json`，没有为凑早期 190 mm 参考值而缩放原脸。

数字检查尚不能代替实物打印与 UFdoll 四分囡囡体试装；材料收缩、眼球品牌、磁铁实测与颈座配合仍需打样确认。壁厚报告是指定区域的方向采样，不是整个模型最小法向厚度的证明。
